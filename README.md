RiskVision — Inteligência Preditiva para Risco Financeiro
Sobre o Projeto

O RiskVision é uma plataforma de análise preditiva desenvolvida para transformar dados financeiros em inteligência estratégica, utilizando técnicas de engenharia de dados, machine learning e dashboards analíticos.

A solução foi criada como parte do Challenge FIAP 2025, em parceria com a Núclea, com o objetivo de apoiar empresas na identificação de riscos financeiros, inadimplência e possíveis fraudes através de análises inteligentes em tempo real.

Problema de Negócio

Empresas frequentemente enfrentam dificuldades para:

identificar riscos financeiros antecipadamente;
detectar padrões de inadimplência;
centralizar indicadores estratégicos;
visualizar grandes volumes de dados financeiros;
detectar possíveis fraudes em tempo hábil;
transformar dados em decisões executivas rápidas.

Além disso, muitos processos ainda são realizados manualmente, aumentando:

tempo de análise;
riscos operacionais;
inconsistências;
baixa previsibilidade financeira.
Objetivo do Projeto

Desenvolver uma solução analítica capaz de:

gerar score de risco financeiro;
classificar empresas em níveis de risco;
identificar comportamentos suspeitos;
fornecer insights estratégicos;
disponibilizar dashboards executivos interativos;
apoiar tomadas de decisão baseadas em dados.
